Hi! Welcome to the Running Skeleton extension repository!

This site is used to deliver automatic updates and preserve the older versions of the Running Skeleton extension for Firefox. Do note that this is an unlisted extension so you cannot install it from AMO.
As mentioned earlier, the older versions of the extension are located in here in the event that you dislike a new feature from a recent update. You should be able to downgrade and continue with an older version if you so choose.

WARNING | Downgrading may erase your data. Installing an older version of Running Skeleton may cause achievements, statistics, settings, custom sounds, and other data to be lost. This may not be recoverable by upgrading.
